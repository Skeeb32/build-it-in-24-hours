# Build It in 24 Hours

A beginner-friendly, self-paced full-stack web development course designed for one focused 24-hour learning window. It is tailored for a macOS learner who knows basic coding and already has Node.js, VS Code, and Git installed.

## Open the course

Open `index.html` in a modern browser. The course is a static site and does not need a build step or package installation.

## What is included

- A paginated, 24-lesson roadmap from setup and HTML/CSS through React, APIs, databases, authentication, GitHub, deployment, and a final review.
- Beginner explanations, examples, guided steps, practice exercises, checkpoints, and completion criteria for every lesson.
- Video lesson suggestions with embedded YouTube tutorials.
- Progress tracking and personal notes saved in this browser.
- Responsive layouts for desktop and mobile screens.

## Learning plan

Use the time blocks as a guide, not a deadline. Take breaks, and spend longer on topics that are new to you. A 24-hour plan is intense; it is fine to spread it over multiple days.

## Project files

- `index.html` — course page structure.
- `styles.css` — visual design and responsive layout.
- `app.js` — lesson content, pagination, video links, and browser-local progress.

Progress and notes are stored in the browser's local storage. They stay on this device and browser profile, and are not synced to an account.
